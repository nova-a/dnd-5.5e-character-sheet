# dnd-5.5e-character-sheet
D&amp;D 5.5e/2024 rules character sheet in HTML/JS/CSS for local use.

Modified version of [/u/Nareto64's character sheet](https://www.reddit.com/r/DnD/comments/1qqje93/best_app_for_character_sheet_2024_edition/o2i64ny/), which in turn is a modified version of [/u/BackFromOtterSpace's sheet](https://www.reddit.com/r/DnD/comments/fvxsgj/5e_html_character_sheet_for_5e_with_basic/).

Disclosure: Some modifications made with GPT 5.6 Sol.

## Usage

Open the html file. Edit your character as desired. Make sure to tick 'autosave' on. This saves your character to browser local storage. I have not tested swapping between multiple characters in browser local storage, so I would recommend falling back on the JSON blob saving mechanism that was previously implemneted for that use case.
